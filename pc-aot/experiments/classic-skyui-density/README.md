# SkyUI 5.1 phone list layout

The hosted planner defines Compact and Large Text presets for the Inventory and Magic menus. Both presets use the same shorter column lists. The inventory presets emphasize name, weight and value. The magic presets emphasize name, cost and school. Both preserve equipment and item icons. The dedicated Shouts, Powers and Active Effects column lists keep their stock structure. The shared spell cost column also changes width in Powers. Where the preset enables a column, it takes precedence over any saved hidden flag on the next opening. The SkyUI column picker can still save the user's choices for use with the default layout.

The setting is opt-in per profile. The host checks the original SkyUI 5.1 archive, SKSE scripts and loose menu/config overrides before queuing extra arguments. On the keys command, it appends keys to the temporary GFx argument vector. On the values command, it reads the live movie, checks its initial `LOAD_FILE` phase, exact key-array length and matching suffix, then appends the values. The stock value command only iterates over the original 128 values when any check fails, even if the keys had already been appended. The original Papyrus arrays and saved MCM overrides are never written. [SkyUI configuration delivery](https://raw.githubusercontent.com/schlangster/skyui/8354287/dist/Data/Scripts/Source/SKI_SettingsManager.psc) · [ConfigManager](https://raw.githubusercontent.com/schlangster/skyui/8354287/src/Common/skyui/util/ConfigManager.as) · [ListLayout](https://raw.githubusercontent.com/schlangster/skyui/8354287/src/Common/skyui/components/list/ListLayout.as)

The fixture compiles the production adapter against a simulated live movie. It checks the outgoing arguments, fallback when key/value calls land in different movies, rejection before and after initial load, and cleanup after failed Scaleform reads. It also closes the active movie during each property lookup. The adapter discards the retired view and releases any temporary values; the replacement can receive its own configuration pair. The original SkyUI SWFs' actual readiness timing, private field access and visible fonts, columns and sort selections still need an iPhone check. A loose file check cannot establish which SWF a competing BSA supplies, so the live config shape is checked again immediately before applying values.

Checking the settings from the verified 5.1 archive against the original layout calculation gives row heights of 24, 20 and 26.4 stage units for Default, Compact and Large Text with the stock icon visibility. Entry font sizes are 14, 13 and 18. The resulting widths were checked for the five inventory and five magic views. The two phone presets give most item names and spells more space after removing optional columns. The name column for keys has less space because the presets widen weight and value. The separate bottom-bar carry-weight readout is unchanged by these column options.
