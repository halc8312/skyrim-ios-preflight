# Skyrim 2011 on iPhone

Experimental source and local-build tools for owners of **Skyrim 2011 / Legendary Edition**.

**[Build and install your own copy](pc-aot/docs/BUILD_YOUR_COPY.md)**

The active game port lives in [`pc-aot/`](pc-aot/README.md) on branch `codex/skyrim-pc-aot-foundation`. The default `main` branch and older probe workflows contain earlier research.

- Use your own English LE game files and Apple signing account.
- The documented route uses Windows once for input preparation and a Mac with Xcode for building and signing.
- Build12 has gameplay evidence on iPhone 17 Pro Max. **iPhone 15 Pro Max / iOS 26 remains unverified.**
- No game files, generated game code, ready-to-play IPA, private credentials or saves are distributed here.

Read the [requirements and current limits](pc-aot/README.md) before starting. The new complete self-build route still needs an independent end-to-end run; the guide separates tool checks from device testing.
